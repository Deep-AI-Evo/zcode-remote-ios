# App Store 上架准备清单 / App Store Submission Checklist

> 状态标记：✅ 已就绪 · 🔧 进行中 · ⬜ 需要用户拍板/提供

## 一、必须项（缺一必拒）

- [x] ✅ **隐私政策 URL**：`PRIVACY.md` 已就绪（需通过 GitHub Pages 或 raw 链接提供可公开访问的 URL）
- [x] ✅ **隐私问卷**：App 不收集任何数据，App Store Connect 隐私标签填"不收集数据"即可
- [x] ✅ **演示模式**：空态页内置「体验演示」入口，审核员无需 ZCode 桌面端即可体验核心交互（DemoView + 内置演示页）
- [ ] ⬜ **App 名称**：⚠️ **核心风险，需要拍板**——"ZCode"是智谱商标，App 名称/副标题带 "ZCode" 会被 Guideline 5.2.1（第三方商标）卡审，需提供授权或改名。建议改中性名，如：
  - 「远程工作台 RemoteDesk」「扫码连接器 LinkPilot」「Workspace Mirror」等
  - 或与智谱取得书面授权后保留现名
- [ ] ⬜ **应用图标**：1024×1024 无圆角 PNG（当前 Z 图标若保留 ZCode 名则同样涉及商标问题）
- [ ] ⬜ **截图**：6.9"（iPhone）与 13"（iPad）各 2-10 张
- [ ] ⬜ **App 描述 / 关键词 / 分类**（建议：开发者工具）
- [ ] ⬜ **年龄分级问卷**（无暴力/赌博等内容，4+）

| 上传功能权限说明 | 5.1.1 | PHPicker 免存储权限，隐私政策已写明 | ✅ 已就绪 |

## 三、审核备注草稿 / Review Notes（模板）

```
本应用是一个"远程工作区连接管理器"：用户在自己电脑上的开发工具中生成
临时连接地址（形如 https://…/remote/v4/...），保存到本应用后即可在手机
上查看与操作自己的开发工作区。

演示方式：首次打开（无任何连接时）点击"体验演示"即可查看内置演示页，
体验全部界面交互（浮动工具条、收起、网页上传选择器等），无需任何外部
账号或设备。

隐私：不收集任何数据（见隐私政策链接）。相机权限仅用于扫描用户自己
电脑屏幕上的二维码。
```

## 四、提交流程

1. Xcode 打开工程 → Product → Archive（真机/通用 iOS Device）
2. 上传到 App Store Connect（Organizer → Distribute App）
3. 填写 metadata（名称/描述/截图/隐私政策 URL/分级）
4. 提交审核；被拒按上方对策逐条回应 Resolution Center
