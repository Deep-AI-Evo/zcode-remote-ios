远程工作区连接演示

本页面用于在无桌面端会话时体验应用功能。真实使用中，这里加载的是 ZCode「手机连接」的官方远程控制页面，可实时查看任务进度、会话内容并进行操作。

🎛️ 浮动工具条

顶部悬浮胶囊：返回列表、刷新页面、更多操作（Safari 打开 / 更换链接），右侧可收起为小圆钮。

🔄 会话同步

真实场景下，桌面端 Agent 的回复与执行进度会实时呈现在此页面，可直接补充需求让 Agent 继续。

💾 本地连接管理

支持保存多条连接、滑动删除、复制链接；重新打开应用自动回到上次的连接画面。

📤 上传功能演示

点击上方按钮可唤起系统照片选择器（无需存储权限）

提示：本应用为第三方工具，仅封装 ZCode 官方「手机连接」网页；连接地址由电脑端 ZCode 生成，请勿外传。
